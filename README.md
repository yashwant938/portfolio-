# Yashwant — Systems × Intelligence

Personal portfolio featuring systems engineering, LLVM contributions, and generative AI projects.

Live website: https://yashwant938.github.io/portfolio-/

## Development

The website is a static site in `docs/`, with no build step or runtime dependencies.

Run `python -m http.server 4173 --directory docs` and open http://localhost:4173.

Edit `docs/index.html` for content, `docs/style.css` for design, and `docs/app.js` for the interactive 3D scene and filters.

## Deployment

GitHub Pages publishes the `/docs` folder on `main`. Push changes to `main` to update the live website.

Content is based on the GitHub profile and project descriptions verified on October 10, 2026. Project illustrations are conceptual graphics. The portrait was supplied by Yashwant. Reduced-motion preferences are respected; motion can also be paused manually.
