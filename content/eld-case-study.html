01 / DIAGNOSTICS · PR #2207MERGED A warning that finds the problem. Making linker-script warnings point to the exact line. BEFORE: file only   →   AFTER: file + line Explore case studyClose case study↗

A linker combines compiled code into an executable. When a linker script declares the same symbol again, a precise warning helps the developer find the conflicting line.

THE INPUT

In the actual regression test, bar is defined and then declared again two lines later:

03  PROVIDE(bar = 3);
04  *(*foo*)
05  PROVIDE(bar = 5);
BEFORE & AFTER
BEFOREscript.t: Ignoring provide symbol 'bar' redeclaration
AFTERscript.t:5: Ignoring provide symbol 'bar' redeclaration

Warning paths shortened for readability; wording matches the test.

THE FIX

Changed the diagnostic to use the existing getContextWithLineNumber() helper, so the warning identifies the repeated declaration.

THE PROOF

ProvideSymbolRedecl checks lines 5, 7, and 9; a second test checks a declaration outside SECTIONS. Both failed before and passed after the fix across six target configurations: 12 focused passes, no skips. The full suite was not run.

02 / LINKER LAYOUT · PR #2065MERGED A linker script that stopped crashing. Handling executable headers that aren't in the output layout. BEFORE: assertion failure   →   AFTER: link succeeds Explore case studyClose case study↗

Executable files have headers that describe their layout. A linker script can place those headers in different ways, including leaving one out of the output layout.

THE INPUT

The added regression test links a small data object with a script that places the program header, but not the ELF header, in a segment:

PHDRS {
  headers PT_LOAD PHDRS;
  data PT_LOAD;
}
SECTIONS {
  . = 0x1000;
  .data 0x1000 : { *(.data*) *(.sdata*) } :data
}

Excerpt from the test fixture; a second case uses FILEHDR instead of PHDRS.

BEFORE & AFTER

Before the fix, address assignment could touch a header absent from the layout and trigger an assertion. After the fix, the test links both header configurations and checks the resulting load-segment offsets and addresses.

THE FIX & PROOF

Guarded ELF and program-header address assignment with isEhdrInLayout() and isPhdrInLayout(). The new regression and surrounding header tests recorded 164 focused passes and 10 expected unsupported skips across six target configurations. The full suite was not run.
