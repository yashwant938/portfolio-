Qualcomm ELD contributions

Qualcomm ELD

Four merged fixes across GNU compatibility, header layout, native LTO output, and linker-script diagnostics.

  • #2011 · GNU numeric -O compatibility ↗Merged

    Unblocked warning-sensitive Meson links while leaving --lto-O controls independent. Regression coverage across six target configurations.

  • #2065 · PHDRS/FILEHDR layout crash ↗Merged

    Guarded header address assignment when a linker script omits headers from the output layout; checked both header combinations.

  • #2129 · Native LTO saved objects ↗Merged

    Preserved native ARM/AArch64 object emission with --save-temps; covered full LTO, ThinLTO, and explicit assembly output.

  • #2207 · Linker-script warning locations ↗Merged

    Included source line numbers in duplicate PROVIDE and PROVIDE_HIDDEN warnings; both updated regressions passed across six target configurations.

  • #2134 · AArch64 feature flags ↗Open

    Preserved BTI/PAC flags across multiple sections in one input. The regression failed before the fix; 18 focused runs passed after it.

  • #2127 · Contributor build guidance ↗Open

    Documented LLVM main alignment and space-free source/build paths following hands-on WSL setup and maintainer discussion.

ELD status checked on 30 October 2026. Test results are recorded in the PRs and cover focused regressions, not the full ELD suite. Open changes remain under review.
